# Онлайн-запись на занятия

Дипломный проект: веб-приложение для онлайн-записи на занятия.

## Технологии

### Backend
- Node.js + Express
- PostgreSQL + Sequelize
- JWT для авторизации
- bcrypt для хеширования паролей

### Frontend
- React
- React Router
- Axios

## Требования

- Node.js 18+
- PostgreSQL 14+
- npm 9+
